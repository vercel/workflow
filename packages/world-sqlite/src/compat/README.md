# Compatibility test inventory

The suites in this directory are world-local's tests, run against world-sqlite through the shim in `storage.ts`, `db-cache.ts` and `test-helpers.ts`. They cover world-local's public behaviour, not its on-disk format: world-sqlite does not read world-local JSON directories.

**98 world-local test declarations were changed: 56 dropped, 42 rewritten** (renamed or replaced tests count as rewritten; an `it.each` counts once). Each row names the world-local test, what it guarded, and either the world-sqlite test that replaces it or the transaction or schema invariant that makes it unnecessary. A transaction is cited only for partial-write and crash windows that cannot occur when the whole operation commits atomically; a schema index is cited only for removed filesystem-index rebuilds. Line numbers are as of the commit that added this file.

Three behaviours the dropped tests covered have direct tests in `coverage-gaps.test.ts`: continuing a run with ULID-numbered events, malformed snapshot blobs loading as `null`, and hook/token cleanup when a legacy run is cancelled. Same-hook publication contention (twelve storage instances racing one `hook_created`) is in `storage/hook-create-publication.test.ts`; those instances are separate connections in one process, not separate processes.
