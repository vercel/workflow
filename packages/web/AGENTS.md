# @workflow/web

Styling rules for this package live in `../web-shared/AGENTS.md`. Read them before changing class names, inline styles, or CSS. The short version: never use opacity to set a text colour. Use the same Geist tokens as the dashboard instead.

Before changing UI in this package, read the [`web-guidelines`](../../.agents/skills/web-guidelines/SKILL.md) skill. For user-facing flows, copy, and states, also load [`product-design`](../../.agents/skills/product-design/SKILL.md).
