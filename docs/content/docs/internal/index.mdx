## Preview Package

Install the workflow package built from this preview deployment:

```bash
pnpm i https://{VERCEL_URL}/workflow.tgz
```

Run the web UI in your project:

```bash
npx workflow@https://{VERCEL_URL}/workflow.tgz web
```

Replace `{VERCEL_URL}` with the preview deployment URL (e.g., `workflow-docs-git-my-branch.vercel.sh`).
