`HookReservedError` is thrown by [`resumeHook()`](/docs/api-reference/workflow-api/resume-hook) and [`getHookByToken()`](/docs/api-reference/workflow-api/get-hook-by-token) when the token is reserved by a run started with [`start({ hook })`](/docs/api-reference/workflow-api/start#prevent-duplicate-starts) that has not registered its hook (`createHook({ token })`) yet. The token has an owner, so this is not a [`HookNotFoundError`](/docs/api-reference/workflow-errors/hook-not-found-error): wait and retry, and the call succeeds once the owner registers the hook.

```typescript lineNumbers
import { resumeHook } from "workflow/api";
import { HookReservedError } from "workflow/errors";
declare const token: string; // @setup
declare const payload: { note: string }; // @setup

async function resumeWhenLive() {
  for (let attempt = 0; attempt < 10; attempt++) {
    try {
      return await resumeHook(token, payload);
    } catch (error) {
      if (!HookReservedError.is(error)) throw error; // [!code highlight]
      await new Promise((resolve) =>
        setTimeout(resolve, (error.retryAfter ?? 1) * 1000)
      );
    }
  }
  throw new Error(`Run did not register its hook in time`);
}
```

If the owner ends without registering the hook, or after registering and disposing it, the lookup answers `HookNotFoundError`. Inside a step, `resumeHook()` and `getHookByToken()` wait for the owner for up to 30 seconds, honoring `retryAfter`, before throwing `HookReservedError`; the step's retries cover a longer wait.

`runId` is the run that reserved the token. `retryAfter` is the World's suggested delay before retrying, in seconds, when it gives one.
