The `@workflow/ai` package is deprecated in Workflow 5 and remains documented for existing applications. `@workflow/ai` 6 contains only `WorkflowChatTransport`; `DurableAgent` is in `@workflow/ai` 5 and earlier. To move an agent off `DurableAgent`, follow the [migration guide](https://ai-sdk.dev/v7/docs/agents/workflow-agent#migrating-from-durableagent). Build new agents with [`WorkflowAgent`](https://ai-sdk.dev/v7/docs/agents/workflow-agent#workflowagent) and [`WorkflowChatTransport`](https://ai-sdk.dev/v7/docs/agents/workflow-agent#resumable-streaming-with-workflowchattransport) from `@ai-sdk/workflow`.
