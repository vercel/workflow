Waits for a slot under a rate limit that every run of the project shares. At most `limit` calls with the same `key` go ahead per `period`, each at least `period / limit` after the one before. A call whose slot is now resolves at once; otherwise the run sleeps until its slot, like [`sleep()`](/docs/api-reference/workflow/sleep), and resolves then.

<Callout type="warn">
Experimental. Runs must be created at spec version 10 ([`WORKFLOW_SPEC_VERSION=10`](/docs/configuration/runtime-tuning#workflow_spec_version)) on the Vercel or Local World, with the default `node` workflow VM. Elsewhere the call throws.
</Callout>

```typescript lineNumbers
import { experimental_rateLimit } from "workflow"

export async function summarize(docs: string[]) {
  "use workflow"
  for (const doc of docs) {
    await experimental_rateLimit({ key: "openai", limit: 60, period: "1m" }) // [!code highlight]
    await callModel(doc)
  }
}
```

## Behavior

- Calls on one key share it across runs, so they are admitted in the order the World receives them. Calls that ask for different rates on one key each use up their own share of its time.
- The rate is per project and environment: preview and production deployments have separate budgets for the same key.
- Keys are stored as-is in the run's event log. Don't put personal data in them.
- A call that cannot get a slot before its `timeout` rejects with [`RateLimitTimeoutError`](/docs/errors/rate-limit-timeout) and uses up none of the key's capacity. Without a `timeout`, a call waits up to a year.

## Examples

### Giving up when the wait is too long

```typescript lineNumbers
import { experimental_rateLimit } from "workflow"
import { RateLimitTimeoutError } from "workflow/errors"

export async function notify(userId: string) {
  "use workflow"
  try {
    await experimental_rateLimit({ key: "sms", limit: 10, period: "1s", timeout: "30s" }) // [!code highlight]
  } catch (error) {
    if (RateLimitTimeoutError.is(error)) return "skipped"
    throw error
  }
  await sendSms(userId)
  return "sent"
}
```
