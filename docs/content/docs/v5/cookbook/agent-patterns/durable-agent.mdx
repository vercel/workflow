<Callout type="warn">
`DurableAgent` is deprecated. For new durable agents, use AI SDK's [`WorkflowAgent`](https://ai-sdk.dev/v7/docs/agents/workflow-agent#workflowagent), the maintained API in `@ai-sdk/workflow`.
</Callout>

This page is kept for existing applications that already use `DurableAgent`. Do not start new implementations with this pattern.

## What to use instead

Use AI SDK's [`WorkflowAgent`](https://ai-sdk.dev/v7/docs/agents/workflow-agent#workflowagent) for new durable, resumable AI agents. The AI SDK docs are the source of truth for the current agent API, examples, and migration guidance.

## Existing DurableAgent users

If you maintain existing `DurableAgent` code, keep using the legacy pattern until you migrate:

- Keep the agent entry point in a `"use workflow"` function.
- Keep side-effecting tool implementations in `"use step"` functions.
- Stream through `getWritable()` only where legacy routes still need workflow output streaming.

For the legacy API surface, see [`DurableAgent` API reference](/docs/api-reference/workflow-ai/durable-agent).
