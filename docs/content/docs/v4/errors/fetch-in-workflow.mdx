This error occurs when you try to use `fetch()` directly in a workflow function, or when a library (like the AI SDK) tries to call `fetch()` under the hood.

## Error message

```text
Global "fetch" is unavailable in workflow functions. Use the "fetch" step function from "workflow" to make HTTP requests.
```

## Why this happens

Workflow functions run in a sandboxed environment without direct access to `fetch()`.

Many libraries make HTTP requests under the hood. For example, the AI SDK's `generateText()` function calls `fetch()` to make HTTP requests to AI providers. When these libraries run inside a workflow function, they fail because the global `fetch` is not available.

## Quick fix

Move the code that makes the request into a step function, and call that step from the workflow. Steps run with full Node.js access, so the global `fetch()`, and libraries such as the AI SDK that call it, work as usual there. The step's return value is recorded in the event log, so the workflow replays deterministically without making the request again.

**Before:**

```typescript lineNumbers title="workflows/ai.ts"
import { generateText } from "ai";

export async function chatWorkflow(prompt: string) {
  "use workflow";

  // Error - generateText() calls fetch() under the hood
  const result = await generateText({ // [!code highlight]
    model: "spacexai/grok-4.6", // [!code highlight]
    prompt, // [!code highlight]
  }); // [!code highlight]

  return result.text;
}
```

**After:**

```typescript lineNumbers title="workflows/ai.ts"
import { generateText } from "ai";

async function generate(prompt: string) {
  "use step"; // [!code highlight]

  // Plain model strings route through Vercel AI Gateway
  const result = await generateText({
    model: "spacexai/grok-4.6",
    prompt,
  });

  return result.text;
}

export async function chatWorkflow(prompt: string) {
  "use workflow";

  return await generate(prompt); // [!code highlight]
}
```

Return only the values the workflow needs (here `result.text`): step return values must be [serializable](/docs/foundations/serialization), and smaller results keep the event log small.

## Common scenarios

### AI SDK integration

For agents, use [`DurableAgent`](/docs/api-reference/workflow-ai/durable-agent), which runs each model call and step-backed tool as a step, so you don't call AI SDK functions from the workflow function yourself.

For a single `generateText()`, `generateObject()`, or `streamText()` call, wrap it in a step function as shown above. Reading the response, streaming included, then happens inside the step.

### Direct API calls

For a plain HTTP request whose response you only need as JSON or text, you can use the `fetch` step function from `workflow` directly in the workflow function:

```typescript lineNumbers
import { fetch } from "workflow";

export async function dataWorkflow() {
  "use workflow";

  // Use fetch directly for HTTP requests
  const response = await fetch("https://api.example.com/data"); // [!code highlight]
  const data = await response.json();

  return data;
}
```

If you need to process the response further, for example to read `response.body` as a stream, make the request and process the response together inside your own step function instead.

For more details on the `fetch` step function, see the [fetch API reference](/docs/api-reference/workflow/fetch).
