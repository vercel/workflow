If you add a new `rule/...` citation anywhere, add a row here first. If a row drifts (slug is cited but no canonical section), fix the citation or add the section.

## Slug Conventions

- **Always prefix with `rule/`.** `name-the-thing` (no prefix) is non-canonical — use `rule/name-the-thing`.
- **Hyphenate multi-word slugs.** `rule/active-voice`, not `rule/activeVoice` or `rule/active_voice`.
- **One slug per concept.** Don’t alias (`rule/voice` is not a separate rule from `rule/active-voice`).
- **Citations in tables** use the slug only. The reader resolves via this registry.
- **Keep `rule/...` copy-specific.** Interface orchestration findings use `interface/...` namespaces and canonical source sections, not this copy rule registry.
